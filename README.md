# Vaibes Android releases

Releases oficiais do aplicativo nativo Vaibes para Android. Este repositório contém apenas artefatos e notas de release; o código-fonte permanece no repositório privado `vaibes-3`.

## Download

- Página do Vaibes: <https://vaibes.com.br/download>
- APK beta 25.0.3: <https://github.com/andrewxr3009/vaibes-releases/releases/download/V2026-25.0.3/vaibes-android-V2026-25.0.3.apk>
- Todas as versões: <https://github.com/andrewxr3009/vaibes-releases/releases>

Confira o SHA-256 e os requisitos descritos nas notas de cada release antes de instalar. As versões beta distribuídas diretamente podem exigir autorização para instalar apps de fontes externas.
